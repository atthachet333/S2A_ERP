# COST CALCULATION — S2A ERP

## Preview and persistence
เมื่อเลือกหน่วยซื้อ `quantityBase = quantity × purchaseToBaseFactor`; line cost คือ `quantityBase × lastCost × (1 + wastePercent/100)` Frontend preview ทันที แต่ backend โหลดราคาล่าสุดและ recompute ก่อน persist

> เงินและปริมาณใช้ **Decimal** เสมอ — ห้ามใช้ Float

## 1. Moving Average Cost (ต้นทุนเฉลี่ยเคลื่อนที่)
ใช้เป็นวิธีต้นทุนวัตถุดิบในเวอร์ชันแรก

```
avgCost_new = (มูลค่าสต๊อกเดิม + มูลค่ารับเข้าใหม่) / (จำนวนเดิม + จำนวนรับเข้าใหม่)

มูลค่าสต๊อกเดิม  = qty_old  × avgCost_old
มูลค่ารับเข้าใหม่ = qty_recv × unitCost_recv
```
- คำนวณ ณ ตอน **รับเข้า** (`PURCHASE_RECEIPT`, `PRODUCTION_OUTPUT`, `TRANSFER_IN`, ...)
- ตอนตัดออกใช้ avgCost ปัจจุบันเป็น unitCost ของรายการ ledger
- ป้องกันหารศูนย์: ถ้า (qty_old + qty_recv) = 0 → คงค่าเดิม/0 ตามกติกา

## 2. องค์ประกอบต้นทุนสินค้า (จากสูตร)
| องค์ประกอบ | ที่มา |
|-----------|-------|
| ต้นทุนวัตถุดิบ | Σ (ปริมาณในสูตร × avgCost วัตถุดิบ) |
| ต้นทุนบรรจุภัณฑ์ | Σ (ปริมาณ × avgCost packaging) |
| ค่าแรง / ค่าไฟ / ค่าน้ำ / ค่าแก๊ส | กำหนดในสูตร |
| ค่าใช้จ่ายโรงงาน / ขนส่ง / อื่น ๆ | กำหนดในสูตร |
| ต้นทุนของเสีย | จากของเสียมาตรฐาน / จริง |

```
ต้นทุนรวม     = วัตถุดิบ + บรรจุภัณฑ์ + ค่าแรง + ค่าไฟ + ค่าน้ำ + ค่าแก๊ส + โรงงาน + ขนส่ง + อื่น + ของเสีย
ต้นทุนต่อหน่วย = ต้นทุนรวม / ผลผลิตจริง (ปรับด้วย Yield)
```

## 3. Yield
```
Yield (%) = (ผลผลิตจริง / ผลผลิตมาตรฐาน) × 100
```

## 4. ต้นทุนมาตรฐาน vs ต้นทุนจริง
- มาตรฐาน (Standard): จากสูตร ณ เวลาวางแผน
- ประมาณการ (Estimated): จากราคาปัจจุบัน
- จริง (Actual): จากปริมาณที่ใช้จริง + ต้นทุน ณ เวลาผลิต
```
ส่วนต่าง (Variance)   = ต้นทุนจริง - ต้นทุนมาตรฐาน
ส่วนต่าง (%)          = (Variance / ต้นทุนมาตรฐาน) × 100
```

## 5. ความแม่นยำ (Precision)
- ราคา/มูลค่า: `Decimal(18,4)`
- ปริมาณ: `Decimal(18,4)`
- เปอร์เซ็นต์: `Decimal(9,4)`
- ปัดเศษเฉพาะตอนแสดงผล ไม่ปัดระหว่างคำนวณสะสม
